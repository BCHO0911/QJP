## 指令编码速查表

### R型: [opcode(5)][rx(3)][ry(3)][rz(3)][func(2)]

| 指令 | opcode | func | 操作 | 格式 |
|:----:|:------:|:----:|:----|:----|
| ADDU | 11100 | 01 | `Rz = Rx + Ry` | ADDU Rz, Rx, Ry |
| SUBU | 11100 | 10 | `Rz = Rx - Ry` | SUBU Rz, Rx, Ry |
| SLL  | 11100 | 11 | `Rz = Rx << Ry` | SLL Rz, Rx, Ry |

### I型: [opcode(5)][rx(3)][imm(8)] 或 [opcode(5)][rx(3)][ry(3)][imm(5)]

| 指令 | opcode | 操作 | 格式 |
|:----:|:------:|:----|:----|
| ADDIU | 01001 | `Rx += imm(8位)` | ADDIU Rx, imm |
| LI | 01101 | `Rx = imm(8位)` | LI Rx, imm |
| LW | 10011 | `Ry = mem[Rx + imm(5)]` | LW Ry, Rx, imm |
| SW | 11011 | `mem[Rx + imm(5)] = Ry` | SW Ry, Rx, imm |
| BNEZ | 00101 | `if Rx≠0 then PC += imm(8)` | BNEZ Rx, offset |
| BEQZ | 00001 | `if Rx=0 then PC += imm(8)` | BEQZ Rx, offset |

### J型: [opcode(5)][rx(3)][ry(3)][reserved(5)]

| 指令 | opcode | 操作 | 格式 |
|:----:|:------:|:----|:----|
| JALR | 00010 | `Ry = PC; PC = Rx` | JALR Rx, Ry |

## 程序1: 移位实现 (乘2、乘4、乘8)

对一个测试数分别左移1位(×2)、2位(×4)、3位(×8)，结果存入内存。

```
地址  汇编代码                  机器码      说明
----  ------------------------ ----------  --------------------------
0:    LI R1, 5                 0x6905     R1 = 测试数据5
1:    LI R2, 1                 0x6A01     R2 = 移位量1 (×2)
2:    LI R3, 2                 0x6B02     R3 = 移位量2 (×4)
3:    LI R4, 3                 0x6C03     R4 = 移位量3 (×8)

4:    ADDU R5, R1, R0          0xE115     R5 = R1 (复制测试数)
5:    SLL R5, R5, R2           0xE557     R5 = R5 << 1 = 5×2 = 10
6:    SW R5, R0, 0             0xD8A0     mem[0] = 10

7:    ADDU R5, R1, R0          0xE115     R5 = R1 (复制测试数)
8:    SLL R5, R5, R3           0xE5B7     R5 = R5 << 2 = 5×4 = 20
9:    SW R5, R0, 1             0xD8A1     mem[1] = 20

10:   ADDU R5, R1, R0          0xE115     R5 = R1 (复制测试数)
11:   SLL R5, R5, R4           0xE597     R5 = R5 << 3 = 5×8 = 40
12:   SW R5, R0, 2             0xD8A2     mem[2] = 40

13:   BEQZ R0, -1              0x08FF     无限循环(HALT)
```

**机器码加载顺序(16进制):**
```
0x6905, 0x6A01, 0x6B02, 0x6C03, 0xE115, 0xE557, 0xD8A0,
0xE115, 0xE5B7, 0xD8A1, 0xE115, 0xE597, 0xD8A2, 0x08FF
```

## 程序2: 16字内存拷贝

将内存 `[16..31]` 区域的16个字拷贝到 `[32..47]` 区域。

```
地址  汇编代码                  机器码      说明
----  ------------------------ ----------  --------------------------
0:    LI R1, 16                0x6A10     R1 = 源地址(16)
1:    LI R2, 32                0x6C20     R2 = 目标地址(32)
2:    LI R3, 0                 0x6B00     R3 = 计数器归零
3:    LI R4, 16                0x6C10     R4 = 循环上限(16)

4:    LW R5, R1, 0             0x99A0     R5 = mem[R1]
5:    SW R5, R2, 0             0xDAA0     mem[R2] = R5
6:    ADDIU R1, 1              0x4901     R1++
7:    ADDIU R2, 1              0x4A01     R2++
8:    ADDIU R3, 1              0x4B01     R3++
9:    SUBU R6, R3, R4          0xE39A     R6 = R3 - R4
10:   BNEZ R6, -6             0x2DFA     若R6≠0，跳转到地址4(LOOP)
11:   BEQZ R0, -1              0x08FF     无限循环(HALT)
```

**机器码加载顺序(16进制):**
```
0x6A10, 0x6C20, 0x6B00, 0x6C10,
0x99A0, 0xDAA0, 0x4901, 0x4A01, 0x4B01, 0xE39A, 0x2DFA,
0x08FF
```

> **注意**: BNEZ的偏移计算: BNEZ在地址10，下一条指令在地址11，目标LOOP在地址4，
> 偏移 = 4 - 11 = -7 → 8位补码 = 0xF9。
> 所以BNEZ R6, -7 编码: 00101_110_11111001 = 0x2EF9
> 同理BEQZ R0, -1 = 00001_000_11111111 = 0x08FF

实际上修正一下BNEZ的偏移计算：

BNEZ在地址10（0-based），经过fetch后PC指向地址11。
目标地址 = LOOP = 地址4
偏移 = 4 - 11 = -7
-7的8位补码 = 11111001

BNEZ R6, -7: 00101 | 110(R6) | 11111001
= 0x2EF9

所以修正的地址10: 0x2EF9

修改后的程序：
```
地址  汇编代码                  机器码      说明
----  ------------------------ ----------  --------------------------
0:    LI R1, 16                0x6A10     R1 = 源地址(16)
1:    LI R2, 32                0x6C20     R2 = 目标地址(32)
2:    LI R3, 0                 0x6B00     R3 = 计数器归零
3:    LI R4, 16                0x6C10     R4 = 循环上限(16)

4:    LW R5, R1, 0             0x99A0     R5 = mem[R1]
5:    SW R5, R2, 0             0xDAA0     mem[R2] = R5
6:    ADDIU R1, 1              0x4901     R1++
7:    ADDIU R2, 1              0x4A01     R2++
8:    ADDIU R3, 1              0x4B01     R3++
9:    SUBU R6, R3, R4          0xE39A     R6 = R3 - R4
10:   BNEZ R6, -7              0x2EF9     若R6≠0，跳转到地址4(LOOP)
11:   BEQZ R0, -1              0x08FF     无限循环(HALT)
```

**最终机器码加载顺序(16进制):**
```
0x6A10, 0x6C20, 0x6B00, 0x6C10,
0x99A0, 0xDAA0, 0x4901, 0x4A01, 0x4B01, 0xE39A, 0x2EF9,
0x08FF
```

## 程序3: 子程序调用累加和

主程序调用子程序计算 1+2+...+10，结果存入 mem[3]。

```
地址  汇编代码                  机器码       说明
----  ------------------------ -----------  --------------------------
0:    LI R1, 10                0x690A      R1 = N = 10 (传递参数)
1:    LI R2, 5                 0x6A05      R2 = 子程序入口地址(地址5)
2:    JALR R2, R7              0x12E0      调用:R7=返回地址,PC=R2
3:    SW R1, R0, 3             0xD843      mem[3] = 累加结果
4:    BEQZ R0, -1              0x08FF      无限循环(HALT)

;--- 子程序: 计算 1+2+...+N ---
; 输入: R1 = N, 输出: R1 = 累加和
5:    ADDU R3, R0, R0          0xE00D      R3 = 0 (累加器)
6:    ADDU R4, R0, R0          0xE011      R4 = 0 (计数器)
7:    ADDIU R4, 1              0x4C01      R4++
8:    ADDU R3, R3, R4          0xE38D      R3 += R4
9:    SUBU R5, R4, R1          0xE436      R5 = R4 - R1
10:   BNEZ R5, -3              0x2EFD      若R5≠0,跳转到地址7(LOOP)
11:   ADDU R1, R3, R0          0xE1      R1 = R3 (结果送R1)
12:   JALR R7, R6              0x17C0      返回:PC=R7
```

> 偏移计算: BNEZ在地址10，目标LOOP=地址7
> 偏移 = 7 - 11 = -4 → 8位补码 = 11111100
> BNEZ R5, -4: 00101_101_11111100 = 0x2DFC? 
> Wait: 00101 | 101 | 11111100 = 0010 1101 1111 1100 = 0x2DFC
> Actually let me recompute:
> opcode=00101, rx=101(R5)=5, imm=-4=11111100
> bits 15-11: 00101
> bits 10-8: 101
> bits 7-0: 11111100
> 二进制: 0010 1101 1111 1100 = 0x2DFC
> 修正地址10: BNEZ R5, -4 = 0x2DFC

修正后的程序：
```
地址  汇编代码                  机器码       说明
----  ------------------------ -----------  --------------------------
0:    LI R1, 10                0x690A      R1 = N = 10 (传递参数)
1:    LI R2, 5                 0x6A05      R2 = 子程序入口地址(地址5)
2:    JALR R2, R7              0x12E0      调用:R7=返回地址,PC=R2
3:    SW R1, R0, 3             0xD843      mem[3] = 累加结果
4:    BEQZ R0, -1              0x08FF      无限循环(HALT)

;--- 子程序: 计算 1+2+...+N ---
; 输入: R1 = N, 输出: R1 = 累加和
5:    ADDU R3, R0, R0          0xE00D      R3 = 0 (累加器)
6:    ADDU R4, R0, R0          0xE011      R4 = 0 (计数器)
7:    ADDIU R4, 1              0x4C01      R4++
8:    ADDU R3, R3, R4          0xE38D      R3 += R4
9:    SUBU R5, R4, R1          0xE436      R5 = R4 - R1
10:   BNEZ R5, -4              0x2DFC      若R5≠0,跳转到地址7(LOOP)
11:   ADDU R1, R3, R0          0xE0      R1 = R3 (结果送R1)
12:   JALR R7, R6              0x17C0      返回:PC=R7(覆盖R6)
```

修正：ADDU R1, R3, R0 的编码
opcode=11100, rx=R3=011, ry=R0=000, rz=R1=001, func=01
二进制: 11100_011_000_001_01 = 1110 0011 0000 0101 = 0xE305

所以:
```
11:   ADDU R1, R3, R0          0xE305      R1 = R3 (结果送R1)
```

**最终机器码加载顺序(16进制):**
```
0x690A, 0x6A05, 0x12E0, 0xD843, 0x08FF,
0xE00D, 0xE011, 0x4C01, 0xE38D, 0xE436, 0x2DFC, 0xE305, 0x17C0
```
