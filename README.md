# Algorithm & Data Structure Templates

A collection of C++ algorithm and data structure implementations for competitive programming.

## Structure

- **algo**: Binary search, difference array, linear sieve, prefix sum
- **ds**: Disjoint set, Fenwick tree, segment tree
- **graph**: BFS, DFS, Dijkstra, topological sort
- **math**: Combinatorics, fast power, GCD
- **string**: KMP, Trie
