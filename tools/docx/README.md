# Docx Tools

Reusable document-generation and document-processing utilities.

- `apply_manuscript.py` - JSON to DOCX assembly.
- `convert_doc_to_docx.py` - legacy DOC to DOCX conversion.
- `format_and_convert.py` - style cleanup and PDF export.
- `generate_docx.py` - sample paper generator.
- `read_template.py` - template text inspection.
- `extract_docx.py` - DOCX extraction pipeline.
- `docx_helpers.py` - shared font helper.
