# Math Modeling Tools

This folder holds the reusable parts of the modeling-paper workflow.

- `gen_moore_paper_docx.py` - generate the sample DOCX.
- `model_optimization.py` - build figures and run the optimization simulation.
- `build_paper.js` - build pipeline entry.
- `src/` - core modeling logic.
- `_docx_tools/` - DOCX cleanup and layout utilities.
- `附录_代码_精简版/` - appendix code bundle.
